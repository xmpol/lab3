# Отчёт по лабораторной №3

## Данные и подготовка

**Линейная регрессия.** Использован `Student_Performance.csv` (10 000 строк, 5 признаков и целевая переменная `Performance Index`). Значения `Extracurricular Activities` преобразованы: `Yes` → 1, `No` → 0. Остальные признаки уже числовые. Данные разделены на обучающую и тестовую части в отношении 80/20 (`random_state=42`). Масштабирование признаков выполняется через `StandardScaler`, обученный только на train. Для устойчивости градиентного спуска целевая переменная внутри обучения также стандартизируется; итоговые коэффициенты переводятся обратно в исходные единицы.

**Классификация.** Использован `german.csv` (1 000 строк, 20 признаков). Файл разделён точкой с запятой (`sep=';'`), поскольку это фактический разделитель исходного CSV. Целевой столбец — `Creditability` (0/1), остальные столбцы — числовые категориальные коды и числовые признаки. Разбиение 80/20 выполнено со стратификацией по целевому классу и `random_state=42`. Для собственной логистической регрессии и k-NN признаки стандартизируются по train; дерево обучается на исходных числовых признаках.

## Гипотезы и эксперименты

1. Стандартизация признаков должна улучшить численную устойчивость и скорость сходимости градиентного спуска.
2. Линейная регрессия должна описывать основную зависимость между учебными факторами и `Performance Index`; качество оценивается по MSE.
3. Для кредитного скоринга линейная логистическая модель должна быть конкурентоспособной на табличных признаках; дерево может улавливать нелинейные зависимости, а k-NN зависит от масштаба и локальной структуры данных.

Собственная линейная регрессия обучалась пакетным градиентным спуском: `learning_rate=0.05`, `epochs=800`. MSE на обучении снизилась с 368.6730 до 4.1697. Собственный логистический классификатор обучался пакетным градиентным спуском по бинарной кросс-энтропии: `learning_rate=0.1`, `epochs=1000`; loss снизился с 0.6931 до 0.4821.

Для сравнения использовалось то же самое разбиение данных: sklearn `LogisticRegression(max_iter=2000, random_state=42)`, `DecisionTreeClassifier(max_depth=5, random_state=42)` и `KNeighborsClassifier(n_neighbors=7)`. В собственной реализации и baseline логистической регрессии применялся порог вероятности 0.5.

## Выводы

Линейная регрессия достигла тестовой MSE **4.0826**. История ошибки показывает устойчивое снижение MSE на обучающей выборке при выбранных параметрах градиентного спуска.

В задаче кредитной классификации собственная логистическая регрессия и sklearn LogisticRegression дали практически одинаковые результаты: Accuracy 0.770, ROC-AUC 0.808, F1 0.845. Это ожидаемо, поскольку обе модели имеют линейную границу решений; небольшое отличие ROC-AUC связано с численной оптимизацией. k-NN показал близкий результат (Accuracy 0.760, F1 0.840), а дерево решений с ограничением глубины уступило по ROC-AUC и F1 на данном разбиении. У дерева выше Precision (0.831), но ниже Recall (0.700), то есть оно реже находит положительный класс. В целом эксперимент не доказывает универсального превосходства одной модели: результат зависит от признаков, параметров и конкретного разбиения.

## Воспроизводимость

Команды для запуска:

```bash
python -m pip install numpy pandas scikit-learn
python run_experiments.py
```

Скрипт `run_experiments.py` повторяет подготовку данных, разбиения, обучение и расчёт метрик, затем перезаписывает `experiment_results.json`. Используется `random_state=42`.
